AESO UDP/TUN plot origins - 2026-05-29
======================================

This file records the origin of the `csv_udp_tun` CSV files and their matching
`plots_udp_tun` plots.

Topology
--------

- Repeater: local WSL machine.
- Client 1: remote machine through SSH TUN path:
  local `tun0` `10.10.10.1` -> remote `tun0` `10.10.10.2`.
- Client 2: remote machine through SSH TUN path:
  local `tun1` `10.10.20.1` -> remote `tun0` `10.10.20.2`.
- Data protocol: UDP at the Python application level.
- Transport underneath: SSH `-w` TUN, therefore encapsulated over SSH/TCP.
- Warmup: 50 samples.
- Count: 2000 exchanges unless stated otherwise.
- Useful plotted samples after warmup: normally 1950.

Common command shape
--------------------

Repeater base:

```
sudo env PYTHONUNBUFFERED=1 PYTHONMALLOC=malloc python3 minimal_epr_fast.py repeater \
  --listen-host-a 0.0.0.0 \
  --listen-port-a 7401 \
  --listen-host-b 0.0.0.0 \
  --listen-port-b 7402 \
  --werner-ar 1 \
  --werner-br 1 \
  --quiet \
  --data-protocol udp \
  --accept-timeout 120
```

Client 1 base:

```
sudo env PYTHONUNBUFFERED=1 PYTHONMALLOC=malloc python3 minimal_epr_fast.py client \
  --repeater-host 10.10.10.1 \
  --repeater-port 7401 \
  --client-id 1 \
  --quiet \
  --plot \
  --plot-dir csv_udp_tun \
  --data-protocol udp \
  --connect-timeout 120 \
  --detect-timeout 120 \
  --cpu 1
```

Client 2 base:

```
sudo env PYTHONUNBUFFERED=1 PYTHONMALLOC=malloc python3 minimal_epr_fast.py client \
  --repeater-host 10.10.20.1 \
  --repeater-port 7402 \
  --client-id 2 \
  --quiet \
  --plot \
  --plot-dir csv_udp_tun \
  --data-protocol udp \
  --connect-timeout 120 \
  --detect-timeout 120 \
  --cpu 1
```

- No `--clock-sync`.
- Default socket buffer.
- No reliable absolute one-way delay because clock offset was not corrected.
- Result shape:
  - client 1: around `55 ms`.
  - client 2: around `-273 ms`.

Notes on plots
--------------

- `plots_udp_tun/sec/*.png` plots delay over time.
- `plots_udp_tun/counter/*.png` plots delay by count index.
- `plots_udp_tun/counter_filtered/*.png` and
  `plots_udp_tun/counter_outliers/*.png` split normal points and outliers.
- `plots_udp_tun/udp_missing/*_udp_missing.png` shows missing UDP count
  positions for UDP runs.
- For cross-machine one-way delay, use only plots whose CSV had clock sync
  enabled.
- For comparing closeness to zero, prefer absolute delay statistics:
  abs p50, abs p95, abs p99, and abs max.
